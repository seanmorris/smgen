# Basic Usage Example

## Create the Project

Initialize an empty directory to receive the standard templates and assets:

```bash
mkdir my-site
cd my-site
smgen init
```

## Write the Home Page

Replace `pages/index.md`:

```markdown
---
title: Hello, Static Site!
---

# Hello, Static Site!

This page was generated by SMGen.
```

## Build and Preview

```bash
smgen build
smgen serve
```

Open <http://localhost:8000>. The generated page is `docs/index.html` unless
`OUTPUT_DIR` selects another directory.
